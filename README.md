Browser-based 2D replay viewer for Counter-Strike 2 demos.

How to run:
    pip install -r requirements.txt
    python app.py


Controls

- Mouse wheel: zoom, drag: pan, double click: reset view
- Space: play / pause
- Left / Right arrow: seek 5 seconds
- Up / Down arrow: next / previous round
- [ and ]: previous / next kill (also the Kill buttons next to the timeline)
- Click a timeline marker or a kill feed entry: jump to 3 seconds before that event
- Hold Tab: scoreboard for the current moment
- Match stats button: full match statistics
- Economy button: equipment value, bank and buy type for every round
